Color Memory Game

Arduino project — 5 LEDs, 5 buttons, I2C LCD. Memory / Simon-says style game with highscore and buzzer sounds.

Screenshot / Wiring Diagram
View Repository
Features
  • 5 buttons & 5 LEDs
  • I2C LCD status display
  • High score saved (EEPROM optional)
  • FF VII victory tune (buzzer)
  • Non-blocking LED pattern while waiting
Wiring (summary)
LEDs: pins 2–6 | Buttons: pins 8–12 (INPUT_PULLUP) | Buzzer: pin 7 | LCD: I2C (0x27)
How to run
  1. Connect components as wiring above.
  2. Upload the Arduino sketch (provided in Download).
  3. Press the first button to start. Enjoy!
